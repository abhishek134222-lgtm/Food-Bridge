
# FoodBridge

Food Donation Management System

## Description

FoodBridge connects food donors with NGOs and authorized
receivers to help reduce food waste.

## Interfaces

- Java Swing desktop application
- Java console application
- Responsive website

## Technology

- Java 21
- Java HTTP Server
- HTML, CSS and JavaScript
- PostgreSQL
- Git and GitHub

## Planned Features

- User registration and login
- Food donation listings
- Donation requests
- Collection status tracking
- Admin dashboard
- Donation history and reports
